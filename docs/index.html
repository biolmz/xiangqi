它有什么

    

    

      

        
完整规则

        
蹩马腿、塞象眼、炮翻山、过河兵、飞将（白脸将）、将死与困毙全部实现，perft 着法数与标准值一致。

      

      

        
不会兜圈

        
局面指纹驱动的循环裁决：三次重复判和、单方长将判负。电脑搜索会主动回避重复局面，不会用同一招反复将军。

      

      

        
三档对手

        
Alpha-Beta 搜索配迭代加深与时间上限，简单／普通／困难三档，困难档会算到 5 至 6 层。

      

      

        
中文棋谱

        
每一步按「炮二平五」的记法实时记录，可回看、可悔棋，将军有独立提示。

      

      

        
纯 Java 内核

        
桌面端与安卓端共用同一套规则引擎和 AI 源码，没有第三方依赖。

      

      

        
体积克制

        
安卓包 41 KB，macOS 包 225 KB；Windows 安装包的 28 MB 里绝大部分是 Java 运行时。
